## [0.1.0] — 2026-11-06

First public version under the CLS-Open "honest v0.1" standard: everything present is
tested, and everything absent is named.

### Added — software
- `seqreport` 0.1.0, standard-library only: streaming FASTA parsing (gzip-aware),
  composition statistics (counts, GC with two explicit denominators, GC/AT skew,
  average molecular weight, k-mers, Shannon entropy, sliding windows), quality checks
  with severities, and three renderings of one report structure (JSON, Markdown,
  self-contained HTML).
- CLI with five subcommands (`qc`, `stats`, `windows`, `kmers`, `report`) and meaningful
  exit codes: `0` clean, `1` data has errors, `2` could not run.
- 230 tests, 99% line coverage; cross-validated against Biopython across 356 comparisons
  (parsing, molecular weight, GC on 200 seeded sequences, refusal behaviour).

### Added — education
- Modules 1–3 as complete 13-part lessons: environment and evidence; types, control flow
  and sequences; functions, modules and error handling.
- Five guided practicals with rubrics, three assignments, two challenges, a 10-question
  quiz with a full answer key, an instructor pack with three delivery plans, and
  mini-project and capstone specifications.
- One executed notebook (`notebooks/01_quality_control.ipynb`, 12 code cells, 0 errors),
  re-executed by CI on every push.

### Added — data and figures
- Real UniProt data (retrieved 2026-11-06, CC BY 4.0): 60 reviewed human proteins
  stratified across length bands, and 8 cytochrome c orthologues. Every file has metadata
  with source, query, licence, record count and sha256.
- `qc_problems.fasta`: the cytochrome c records with seven defects planted on purpose,
  each documented in its metadata and asserted by tests.
- Four figures, regenerated byte-identically from data across hash seeds.

### Fixed during development (kept because the lessons use them)
- The initial dataset was the first 60 human proteins sorted by accession, which were
  almost all 100–150 aa — real data, but not the "diverse panel" the documentation
  claimed. Replaced with stratified sampling, and the artefact is now a taught example in
  Module 4's data discussion and in Figure 1's caption.
- `molecular_weight(strict=False)` raised `KeyError` on a corrupt record containing `1`;
  it now skips any residue without a tabulated mass and the QC layer reports the
  character separately. Found by the planted-defect dataset, which is what it is for.
- The CLI caught `FastaError` in two places; the inner handler was dead code and
  untestable. Removed, so the error reaches exactly one handler.
- `GC content of "GCUU"` was asserted as 1.0 in an early test; the correct value is 0.5
  because `U` belongs in the denominator. The test was wrong, not the code.

### Known gaps
- Modules 4–8 (large-file parsing and pandas, plotting, testing and documentation,
  packaging and CLI) are specified in the roadmap and not written.
- No DOI has been minted; Zenodo archiving is an owner action, not a claim.
