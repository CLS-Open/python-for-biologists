# Licensing of this repository

This repository uses a **split licence**, because prose and code need different
terms: prose benefits from attribution-only reuse (translation, remixing,
course packs), while code benefits from maximum permissiveness.

| Path | What it is | Licence |
|---|---|---|
| `src/`, `tests/`, `scripts/`, `examples/` | software | **MIT** (see `../LICENSE`) |
| code cells inside `notebooks/*.ipynb` and `notebooks/*.py` | software | **MIT** |
| `docs/`, notebook markdown cells, `README.md`, `projects/`, `datasets/README.md` | educational content | **CC BY 4.0** |
| `datasets/sample/*` | **real records retrieved from UniProt** (see `datasets/metadata/`) | **CC BY 4.0** — original data © the UniProt Consortium, retrieved 2026-11-06, redistributed under CC BY 4.0 with attribution |
| `datasets/sample/*derived*` | records we deliberately corrupted to create QC test cases | **CC BY 4.0**, derived from the above; every alteration is listed in the metadata file |
| `docs/instructor/` | teaching materials | **CC BY 4.0** |
| Figures in `figures/` | generated by `scripts/make_figures.py` | **CC BY 4.0** |

## What we ask, but do not require

- If you translate the material, open an issue so we can link your version.
- If you teach from it, tell us what broke — adoption reports are the most
  useful contribution this project can receive.
- **Do not** feel obliged to cite this repository in academic work that did not
  use it. Citation inflation is a form of misconduct we explicitly do not request.
